# PersianTextGuard default word list: Persian, Finglish and English.
#
# Opt-in: used only when you pass WordList.PersianDefault to ProfanityFilter. Treat it as
# a starting point for your community, not a finished list.
#
# ── How to read this file ──────────────────────────────────────────────────────
#
#   word or phrase     matched as whole words only (the default, and the safe one)
#   ~word              matched anywhere, inside longer words too
#   # ...              a comment
#
# Every entry is normalised with PersianNormalizer on the way in, so Arabic yeh/kaf,
# zero-width characters and tatweel need no entries of their own. Neither do the evasions
# ProfanityFilter reads through: letters spaced or dotted apart («ک ی ر», f.u.c.k), a held
# key («کیییر», fuuuck), digits and symbols for letters (sh1t, $hit, k0s), filler inside a
# word (f*ck) and Cyrillic or Greek look-alike letters. What IS listed below are the evasions
# that are spelling rather than typography: ص/ث for س, Finglish, and the misspellings people
# settle on (fuk, biatch, niqqa).
#
# ── What is deliberately NOT here ──────────────────────────────────────────────
#
# Public lists ban ordinary words, and a filter that rejects a normal message teaches people
# it is broken rather than that a word is banned. Left out on purpose, with the reason:
#
#   «کس»      also "person": «هر کس», «کس دیگه». Its insults are listed as compounds
#             and phrases instead («کسکش», «کس ننت», «کس خل»).
#   «کردن», «بکن», «دادن», «خوردن»   ordinary verbs.
#   «ساک»     a bag. «ساک زدن» and «ساک بزن» are listed.
#   «تخم»     an egg. «تخمی» and «تخم سگ» are listed.
#   «گه»      also «گه‌گاه» (now and then).     «عن»   also «عن‌قریب».
#   «لخت»     also "bare".   «داف», «ماچ», «دوست دختر»   not profanity.
#   «خر», «گاو», «سگ», «الاغ», «احمق», «خنگ», «بدبخت», «عوضی»   mild or everyday.
#   «ترک», «لر», «عرب», «فارس», «رشتی»   ethnic NAMES, not slurs — banning them bans
#             the people. Slurs built on them belong in your own list as phrases.
#   «شیت» (also "sheet"), «بیچ» ("beach"), «دیک», «گاید» ("guide").
#   ass inside a word (assassin, pass, class), cum inside a word (document), rape inside a
#   word (grape, therapist), dick/cock inside a word (Dickens, peacock, cockpit): all of
#   these are whole-word entries only.
#   hell, damn, crap, bloody, wtf, noob, trash: mild, and ordinary chat.
#   jap: also a common short form for Japan.
#
