# PersianTextGuard — English entries.
#
# Persian chat is full of English swearing, so the bundled list carries it too. The matcher
# reads through leetspeak (sh1t, $hit), held keys (fuuuck), spaced letters (f u c k), filler
# (f*ck), masked letters (f**k), accents (fück) and look-alike Cyrillic or Greek letters, so
# only genuinely different spellings belong here (fuk, biatch, niqqa).
#
# See persian.txt for the format and the categories.
#
# ── What is deliberately NOT here ──────────────────────────────────────────────
#
# Almost everything is a whole-word entry, because English profanity hides inside ordinary
# words: "ass" in assassin, class and pass; "cum" in document and circumstance; "rape" in
# grape and therapist; "shit" in shiitake and Matsushita; "nigger" in sniggered; "pussy" in
# pussycat; "cunt" in Scunthorpe; "cock" in peacock and cockpit; "tit" in title. Only stems
# whose every extension is offensive are matched anywhere (~fuck, ~bitch, ~asshole).
#
# hell, crap, bloody, wtf, noob, trash, suck, screw, balls, boob, hooker and the rest of the
# ordinary-in-context words are in [mild], not in WordList.PersianDefault.
#
# ── Sources ────────────────────────────────────────────────────────────────────
#
# Curated from LDNOOBW (CC BY 4.0), LDNOOBW V2 (CC0 1.0), dsojevic/profanity-list (MIT) and
# Surge AI's Obscenity List (MIT), whose categories and severity ratings this file follows.
