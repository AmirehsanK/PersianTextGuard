# PersianTextGuard — Finglish entries: Persian written in Latin letters.
#
# Finglish has no fixed spelling, so this file carries the spellings people actually type,
# not one canonical form. The matcher already reads through held keys (kiiir), digits and
# symbols for letters (k0s, k!r), spaced or dotted letters (k.i.r) and masked letters (k**r),
# so only genuinely different spellings belong here.
#
# See persian.txt for the format, the categories, and what is deliberately left out.
# «kos» is listed where Persian «کس» is not: in Latin letters it is not the ordinary word
# for "person", and «kasi», «kosar» and «kiriakos» are different tokens.
